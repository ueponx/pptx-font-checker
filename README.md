# pptx フォント診断

Macで開くと文字化けするPowerPointファイル(.pptx)の原因を、ブラウザだけで診断するツールです。

Macにない日本語フォント(BIZ UDPゴシックなど)、フォントのサブセット埋め込み、Googleスライド由来のWebフォントなど、文字化けの原因になりやすい設定を見つけて、対処法とあわせて表示します。

## こんな症状に

- Google Classroomなどで配布したpptxが、Macで開くと文字が□(豆腐)になる
- テキストボックスをクリックすると正しく表示されるのに、別のスライドに移るとまた化ける
- Windowsでは問題ないのに、Macだけおかしい

症状と原因の詳しい解説と、このツールを作った経緯はブログ記事にまとめています。

- 事件編(原因の調査とpptxのフォント指定の仕組み) https://uepon.hatenadiary.com/entry/2026/10/17/134112
- ツール編(このツールの使い方と作り方) <!-- ここにツール編のURL -->

## 特徴

- **オフラインで動作** HTMLファイル1枚で完結し、ネット接続は不要です
- **ファイルを外部に送信しない** 選んだファイルはブラウザの中だけで処理されます
- **インストール不要** ダウンロードしてダブルクリックで開くだけです
- **複数ファイルをまとめて診断** 一度に何個でもドロップできます
- **結果をテキストでコピー** 資料の作成者に直してほしい点を伝えるときに便利です
- **修正版を別名で保存** 原因のフォントをテーマごと置き換えた修正版を作れます。元のファイルは変更しません

## 使い方

使い方は2通りあります。どちらの場合も、pptxの中身が外部に送られることはありません。

| 使い方 | 向いている人 |
| --- | --- |
| ダウンロード版 | 業務資料や個人情報を含む資料を診断する人、ネットに接続していないPCで使う人 |
| GitHub Pages版 | まず試してみたい人、公開済みの資料を診断する人 |

機密を含む資料を診断する場合は、**ダウンロード版をおすすめします**。理由は「セキュリティについて」に書いています。

### ダウンロード版

1. `pptx-font-checker.html` をダウンロードする
2. 必要に応じて、後述のハッシュ値で改ざんされていないかを確認する
3. ダブルクリックしてブラウザで開く
4. 診断したいpptxをドロップする(クリックしてファイルを選ぶこともできます)

ネットに接続していないPCでもそのまま使えます。

### GitHub Pages版

次のページを開いて、pptxをドロップしてください。GitHubと通信するのはページを読み込むときだけで、その後の処理はすべて手元のブラウザで行われます。

## 診断する内容

| 項目 | 内容 |
| --- | --- |
| フォントの埋め込み | 埋め込みの有無、方式(サブセットか全文字か)、埋め込まれたフォント名とサイズ |
| Webフォント | Noto Sans JP、M PLUS系、RobotoなどGoogleスライド由来のフォント |
| テーマの既定フォント | 見出しと本文の英数字用、日本語用のフォント。日本語用が未指定の場合も知らせます |
| 使われているフォント | 全フォントの一覧と分類、用途(英数字用、日本語用、その他の言語用など)、使われているスライド番号やテーマ、使用回数 |

## 判定の見方

| 判定 | 意味 |
| --- | --- |
| 要修正 | フォントがサブセットで埋め込まれています。文字化けの原因として最も疑わしい状態です |
| 要注意 | Macにない可能性が高い日本語フォント(BIZ UDPゴシックなど)、Googleスライド由来のWebフォント、全文字のフォント埋め込みのいずれかがあります |
| 問題なし | 文字化けの原因になりやすい設定は見つかりませんでした |

このほか、Windows向けの英数字フォントやMac向けのフォント、ツールに登録されていないフォントは「確認」として表示します。

### フォントの分類

| 分類 | 例 | 説明 |
| --- | --- | --- |
| 両OS標準 | 游ゴシック、游明朝、Arial | WindowsとmacOSの両方に標準で入っています |
| Webフォント | Noto Sans JP、M PLUS 1p、Roboto | Googleスライドなどで使われるフォントです |
| Office同梱 | メイリオ、MS Pゴシック、MS明朝 | macOS本体にはないが、Office for Macと一緒にインストールされます |
| Windows日本語 | BIZ UDPゴシック、UDデジタル教科書体、Meiryo UI | Macにないと文字が□(豆腐)になることがあります |
| Windows向け | Calibri、Segoe UI、Aptos | 英数字用。Macにないと別のフォントで表示されます |
| Mac向け | ヒラギノ角ゴシック、Osaka、Helvetica | Windowsには入っていません |
| 未登録 | 上記以外 | 配布先にあるかは判定できません |

分類は代表的なフォント名による目安です。最終的には配布先と同じOSで開いて確認してください。

## 対応ブラウザ

ブラウザ標準のzipの展開と圧縮の機能(`DecompressionStream`、`CompressionStream`)を使っているため、比較的新しいブラウザが必要です。

- Google Chrome、Microsoft Edge 103以降
- Firefox 113以降
- Safari 16.4以降

## 制限事項

- パスワード付きのpptxは診断できません。パスワードを外してから試してください
- 古い形式の.pptファイルには対応していません。pptx形式で保存し直してから試してください
- スライドマスターが複数ある場合、テーマの既定フォントは最初のスライドマスターのものを表示します
- 修正機能が置き換えるのは、フォントの指定と埋め込みフォントだけです。文字のはみ出しなどレイアウトの調整はしません
- 修正後のファイルは、PowerPointで正しく開けることを確認してから配布してください

## 修正機能

「要注意」や「要修正」の原因が見つかると、診断結果の下に「修正して別名で保存」が表示されます。

1. 置き換えるフォントと置き換え先を選ぶ(既定はメイリオ。明朝系はＭＳ Ｐ明朝、英数字のWebフォントはArial)
2. 埋め込みフォントがある場合は、外すかどうかを選ぶ
3. ［修正して別名で保存］を押すと保存ダイアログが開くので、保存先とファイル名を決める
4. 保存したファイルの診断結果が、その場で下に表示される

元のファイルは変更しません。置き換えの対象は「Windows日本語」と「Webフォント」に分類されたフォントだけです。記号フォントや、意図して使っているほかのフォントには触れません。

置き換えるのは、スライド、レイアウト、マスター、ノート、配布資料、テーマの各所にあるフォントの指定です。PowerPointの「フォントの置換」では変わらないテーマの既定フォントや、その他の言語用の指定もまとめて置き換えます。

保存ダイアログはChromeとEdgeで開きます。FirefoxとSafariでは、ブラウザのダウンロード先に保存されます。

⚠️ フォントが変わると文字の幅や行の高さが変わるので、保存したファイルをPowerPointで開いて、文字のはみ出しや改行のずれがないか確認してください。

## PowerPointで直す場合

1. ［ホーム］→［置換］→［フォントの置換］(Macはメニューバーの［フォーマット］→［フォントの置換］)で、原因のフォントをメイリオなどに置き換える
2. ［表示］→［スライドマスター］→［スライド マスター］タブの［フォント］→［フォントのカスタマイズ］で、テーマの既定フォントも置き換える
3. サブセット埋め込みがある場合は、保存設定で「ファイルにフォントを埋め込む」をオフにする

閲覧だけでよい資料は、PDFで配布するのがいちばん確実です。

## しくみ

pptxの正体はzipファイルで、中にはスライドごとのXMLや埋め込みフォントのデータが入っています。このツールは次の手順で診断しています。

1. zipの目次(セントラルディレクトリ)を読み、必要なXMLだけをブラウザ標準の `DecompressionStream` で展開する
2. `presentation.xml` から埋め込みフォントの一覧と埋め込み方式を読む
3. テーマ、スライドマスター、レイアウト、各スライドのXMLから、指定されているフォント名を集計する
4. フォント名を分類し、判定と対処法を表示する

外部のライブラリは使っていません。画像や動画などのデータは展開しないので、大きなファイルでも軽快に動きます。

### 判定で気をつけていること

PowerPointのファイルには、埋め込みをオフにしていても `saveSubsetFonts` という設定が既定で残っていることが多くあります。この設定の有無だけで判断するとほぼすべてのファイルが警告対象になってしまうため、このツールは **実際にフォントのデータがファイルに含まれているか** を基準に判定しています。

## セキュリティについて

### ファイルが送られない理由

- **送信処理がない** pptxはブラウザのメモリに読み込み、その場で展開して結果を表示するだけです
- **ブラウザが通信を止める** ページに Content Security Policy(CSP)を設定し、外部との通信や外部リソースの読み込みをすべて禁止しています。仮にスクリプトが通信しようとしても、ブラウザが実行を拒否します
- **中身を確認できる** ソースコードは `pptx-font-checker.html` 1ファイルだけで、外部のライブラリも使っていません

### 送られていないことを自分で確かめる

ChromeかEdgeなら、次の手順で通信が発生しないことを確認できます。

1. ツールを開いた状態で `F12` キー(Macは `Command + Option + I`)を押し、開発者ツールを開く
2. 「ネットワーク」(Network)タブを選ぶ
3. 一覧に何か表示されていれば、消去ボタンで空にする
4. pptxをドロップして診断する
5. 一覧に新しい通信が1件も追加されないことを確認する

### ダウンロード版をおすすめする理由

GitHub Pages版は、リポジトリの持ち主のアカウントが乗っ取られた場合などに、中身を書き換えられる可能性があります。CSPもHTMLの中に書かれているため、HTMLごと書き換えられると保証になりません。

ダウンロード版なら、確認したその版が手元に残り続けます。機密を含む資料を診断する場合や、「外部のWebツールに業務ファイルを読み込ませない」というルールがある職場では、ダウンロード版を使ってください。

### ハッシュ値による改ざんの確認

ダウンロードしたファイルが公開したものと同じかどうかは、SHA-256のハッシュ値で照合できます。

| バージョン | SHA-256 |
| --- | --- |
| 1.0.0 | `e33acf8890256604c210b98a3ee80726afa899a9b795c092b4682d7c96f42dbe` |

確認するコマンドは次のとおりです。表示された値が上の表と一致すれば、改ざんされていません。

Mac(ターミナル)

```bash
shasum -a 256 pptx-font-checker.html
```

Windows(PowerShell)

```powershell
Get-FileHash pptx-font-checker.html -Algorithm SHA256
```

同じハッシュ値をブログ記事にも掲載しています。GitHubとブログという別々の場所の値が一致することで、どちらか一方だけが書き換えられた場合にも気づけます。

### 残るリスク

ブラウザの拡張機能の中には、開いているページの内容を読み取れるものがあります。これはこのツールに限らず、すべてのWebページに共通するリスクです。機密を含む資料を扱う場合は、信頼できない拡張機能を入れていないブラウザで使ってください。
